MICR System Codes Reference

Magnetic Ink Character Recognition architecture and clearing code distributions.

The 9-digit MICR system helps automated systems read and route financial checks during regional clearing processing. This numeric structure directly identifies the location, financial institution, and specific bank branch involved.

Structural Routing Architecture Breakdown

A standard 9-digit MICR code uses a precise 3-3-3 numeric sequence:

  • Digits 1–3: City Location Identifier (matches the first three digits of the local PIN code).
  • Digits 4–6: Bank Brand Identifier (unique identifier for each banking institution).
  • Digits 7–9: Specific Branch Location Identifier.
